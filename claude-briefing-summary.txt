## WHAT'S NEW IN v11 (Nov 23, 2026) — THE MOST IMPORTANT ADDITION

**[BRENT, CRITICAL] A "SPAC merger – first day" stock is NEVER a 40% trade. Run every merger/"begins trading" headline by Claude BEFORE entering.**

EVRL (Everli Global Holdings, formerly Melar Acquisition Corp. I / MACI), Nov 23, 2026: Brent entered at 40% without running it by Claude first. The headline ("Everli begins trading on Nasdaq after merger with Melar" / "Everli Debuts on Nasdaq as EVRL, Setting Out to Lead Grocery Tech in Italy and Beyond") read like routine new-listing news. The release itself contained the full stacked-risk set:
- Newly-CLOSED SPAC merger (closed Nov 20), first day trading under the new ticker = true 0 days traded
- CAYMAN Islands SPAC (re-domiciled to Nevada at closing)
- Redemption rate NOT disclosed ("additional information in an 8-K to be filed")
- $200M Standby Equity Purchase Agreement (SEPA) with Yorkville (YA II PN, Ltd.), 36 months, sales start once a resale registration is effective = live equity line
- Only the majority holder (Palella Holdings) locked up (6 months); nothing said about other holders; warrants also trading (EVRLW)
- No revenue, profit or cash figures anywhere in the release
- Old ticker MACI ran up ~62% right before the debut → the previous close (~$13.30) was an inflated, spiked baseline, well above the ~$10 trust value

Outcome: fills 30 @ $7.98, 30 @ $6.25, 30 @ $4.32 (avg $6.183, $556.50 in). Day low ~-69% from the previous close. Exited all 90 @ $3.55 → **loss $237.00 (-42.6%), Brent's worst loss in many months.** Correct tier: 85% or STAY AWAY (same pattern as BKHA/VESI, Nov 20, which hit -79%).

**Standing rules added:**
1. Any headline with "begins trading," "debuts," "completes business combination," or "merger with [X] Acquisition Corp" = SPAC merger until proven otherwise → run it through Claude BEFORE entering. Never default to 40%.
2. First question on ANY merger headline: is one side an "Acquisition Corp"? If yes, it's a SPAC, with completely different rules from a regular merger.
3. Yorkville / SEPA / "standby equity purchase" / "committed equity facility" in the release = equity line → 85% or don't go in.
4. On any SPAC merger, check the OLD ticker's prior-day % move. A big pre-debut spike means the previous close isn't a fair baseline → spiked-stock/flush rules apply on top of the SPAC rules.
5. If already in one: cancel tier-2/tier-3 orders (no floor, same as toxic warrants). A break-even exit on a bounce is a good outcome. Decide a partial-sell level and a final exit up front.

**[BRENT] Order size updated:** ~$200–$250 per order (three tiers ≈ $600–$750 total) while learning. Replaces the flat $700 per-trade allotment.

**[CLAUDE-SUGGESTED] Up-market inverse of the selloff rule (SMX).** A stock down 25% on a promotional/"fluff" release on a day the Nasdaq is sharply UP (+6%) → the release isn't the reason. Treat as a no-news drop (52.5% dollar / 68.5% penny), not a 40% misc update.

**[CLAUDE-SUGGESTED] "Strategic alternatives" quoted inside a positive release still counts (DCGO).** DocGo's asset-sale release (stock UP ~44%) had the CEO confirming an ongoing strategic-alternatives review, plus "high level of debt," going concern and Nasdaq listing in the boilerplate. **[CLAUDE] Healthcare SERVICES ≠ medical device maker (DCGO).** The 1-2 drug/device no-news-scalp skip rule and the drug-phase tiers apply only to companies with their own drugs/devices in trials, under FDA review, or approved. A services company (mobile health, transport, monitoring other makers' devices) gets the healthcare +5% bump, not the device rules.

## CLAUDE'S ROLE

Core job:
- Analyze articles/SEC filings/the "Claude Dump" sent during trading hours
- Flag red flags ONLY from the specific article/filing sent (not outside sources)
- EXCEPTION: Flag delisting dates found in other sources. [v10] Passive by default (Brent's code checks Form 25); Claude digs in actively only when something hints at it (Asian stock, pink sheet, serial reverse splits, recent compliance notice mentioned, etc.)
- Calibrate SEVERITY — not just identify keywords
- Map to the correct entry percentage — checking for a more specific, already-established rule BEFORE falling back to a generic category default [v8]
- Flag stacking red flags
- Leave ALL trade decisions to Brent
- When no red flags: say "No red flags found" with a brief point-form description
- **[v11] Help Brent review every trade afterwards and keep the call-tracking log.**

Format:
- **Always open with the two tier lines, exactly:**
  ```
  FAST DROP (Jay): __%   — base tier if it drops fast; use the 5%-bounce bump-down
  SLOW / NO FAST DROP (Claude): __%   — red-flag-adjusted tier
  ```
- Then brief point-form details, inside a code block so it pastes cleanly.
- **Always state going-concern status explicitly**: EXISTS (confirmed; quote it and say where it's from), UNCONFIRMED (boilerplate or risk-factor-only), NOT MENTIONED, or COULDN'T CHECK (filing not read).
- **Delisting-date check is PASSIVE by default** [v10]. Report what's found either way.
- If a named category or a [JAY] rule applies, state that tier even when the article is clean.
- If two tiers are plausible, give the [JAY]/table tier and note the alternative in one line.
- Jay's tier is final on entry percentages. Claude still states the risk it sees in one line.
- If the stock is UP on the news, say so prominently — positive spike = no play.
- When Brent pushes back, Claude re-checks honestly against the rules and the filing — not just agrees, not just defends. This includes: a more specific rule skipped for a generic default [v8]; a red-flag markup applied to a situation an existing rule treats as clean [v9]; a clean default (acquirer = 40%) applied despite a self-disclosed repayment-risk statement, or strategic-alternatives + debt stacking under-weighted [v10]; **a "merger"/"begins trading" headline not checked for SPAC origin [v11].**
- Keep it brief and pastable.

Access notes [v11]:

Fix: add an environment variable SEC_USER_AGENT (name + contact email) to the Default environment in claude.ai settings, then start a new session. Procedures:

4. **Price check:** Compute % from the PREVIOUS CLOSE (never the intraday high). Under roughly 18-21% = likely no-trade.
5. **Timing check:** Pre-market or regular-hours news from yesterday = digested. After-hours news = today is the reaction day [BRENT]. Digestion does NOT soften Chapter 11 risk [v9/v10].
6. **Zero days traded:** (a) existing company with a new symbol, (b) SPAC de-merger, (c) IPO/direct listing/spin-off, or (d) data error. Find the old ticker's previous close.

8. **Asian check:** filing address AND officer/director names [JAY, v6]. Watch for US mail-drop addresses (CENN).

Yorkville SEPA), convertibles, warrants (zero-price/reset), authorized-share increases, reverse-split authority, **new preferred stock issued as deal consideration (check conversion terms) [v11]**. Also non-convertible notes with self-disclosed repayment risk [v10].

11. **Market check:** many unrelated stocks dropping → check Nasdaq/VIX. **[v11] Inverse: a single stock down big on a strongly UP market day isn't explained by fluff news (SMX).**
12. **Going-concern language check:** CONFIRMED vs BOILERPLATE/risk-factor-only (see v7). Only confirmed triggers the 85%/STAY AWAY rule; weigh disclosed liquidity facts on their own.
13. **SPAC announcement vs. closing vs. first trade day:** a long-trading shell announcing a target is ordinary news on an existing ticker (65% baseline). A newly-closed SPAC merger trading for the FIRST time under its new ticker is a true 0-days situation with the full stack (BKHA/VESI, EVRL → 85%/STAY AWAY).
14. **Truncated long filings:** say so and name the sections not reached.

## ENTRY PERCENTAGE RULES

### Dollar vs Penny
- Dollar stock: $1.00 and above (including exactly $1.00)
- Penny stock: Below $1.00

### No-News
- Dollar stock: 52.5%
- Penny stock: 68.5%
- **[v11] A promotional/fluff release that doesn't explain the drop (especially on a strongly up market day) = no-news tier (SMX).**

### Non-News (minor news, doesn't affect fundamentals)
- Dollar stock: 52%
- Penny stock: 67.5%

### Asian Stocks
- **Asian countries: China, Taiwan, Hong Kong, Japan, Korea, Macau, Singapore, Malaysia, Thailand**
- **[JAY, v6] Several Asian officer/director names = Asian stock, even with a US address (CENN)**
- No significant news: 80%
- Significant news (reverse split, offering, delisting, ticker change, partnership, any news): 85%
- **[JAY] Asian tier takes precedence over every other rule**
- **[JAY, v5] Asian stock with a share offering: enter 85% below the offering price** (RYOJ, Nov 19 2026: live equity line, no fixed price → 85%)
- India = TBD — check with coach
- NOT Asian (standard rules): Israel, Australia, Canada, UK, Ireland, Netherlands, Greece, Italy, most of Europe, UAE/Dubai. Recent: Cyabra, DETX, Onfolio, Omeros, TruGolf, Gelteq, Grandstand, FNUC (Canada), MCRP (Dubai/UAE), SMX (Irish PLC, Israel-linked; a Singapore partner doesn't make it Asian), EVRL (Italy)

### Earnings
- Use Seeking Alpha headline EPS (GAAP or Non-GAAP). No SA coverage + GAAP/adjusted diverge on a one-time item → use adjusted (KYNB)
- Net income: 40% base; 52.5% with other red flags (dividend cut, layoffs, guidance problems, delisting risk) [BRENT, v5]
- Single amicable leadership departure, no other red flags: 25-30% [JAY, v10] — not a markup
- Net income from a one-time non-operating gain is NOT "clean" [v8]
- Net income + strategic alternatives + guidance cut + debt >> cash → 70% (GRSD) [v10]
- **Net loss: 50% default** [BRENT, ADXN]
- **[JAY, v5] Chapter 11 risk / restructuring (CRO hired, restructuring committee) = 70%, overrides the net-loss 50%** (LVWR); holds regardless of digestion time (TROX)
- **[BRENT] Net loss where the entry would land under $1.00 → 65%** (IHRT)
- EPS miss severity: clean beat/mild miss 40%; moderate miss or guidance cut 45-52%; major miss (40%+) + declining comps 50-52%; confirmed going concern + forbearance + debt crisis 65-70%
- [CLAUDE-SUGGESTED, v6] Net income + guidance cut or core-volume miss on growth/healthcare: 52.5-60% (VCYT)
- [CLAUDE-SUGGESTED, v6] Huge net loss stack (goodwill wiped, guidance suspended, debt >> cash, equity deficit, compliance risk): 50% default, 60% alternative (TEAD; GEOS → 60%)
- [CLAUDE-SUGGESTED, v7] Break-even quarter from preferred-dividend/accretion items in a healthy, growing company: still 50% absent other flags, note context (RMIX)
- [CLAUDE-SUGGESTED, v8] Big net loss from one-time debt-extinguishment charges with an improving balance sheet: read the release first (ONFO 85% → 70%, then back to 85% after the delisting determination) — re-check recurring tickers
- [CLAUDE-SUGGESTED, v9] Serial reverse splits + ongoing ATM + related-party debt → above 50% (KITT 65%)
- Guidance cuts: mild cut + strong offsets 40% (SNWV); no offsets 50-52%; + other red flags 60%+ (FLNC); revenue reaffirmed but profitability guidance sharply worse = still a cut (PRE 55%)

## HALT STRATEGY — CRITICAL RULES [REWRITTEN v11]

[BRENT, v11 CORRECTION] v10 mislabeled T12 as a volatility halt. T12 = additional information requested by Nasdaq = waiting on news.

### Volatility Pause — codes M / LUDP / LUDS (Limit Up–Limit Down)
- M and LUDP = the same thing: Volatility Trading Pause (label differs by exchange/feed). LUDS = straddle variant (lopsided market at the band edge).
- Triggered by SPEED: price moves outside its LULD band (~5-10%, wider under $3) vs. the 5-minute average
- Usually a 5-minute pause, reopens via auction; can extend or repeat (waterfall risk)
- Already know why it's dropping → check existing news for red flags
- Clean fundamentals, single pause → order at 10% below the halt price
- Repeated pauses / cascade → the 10%-under rule does NOT apply
- Distressed stock = 65% minimum OR STAY AWAY
- Strong fundamentals = still cautious, wait for stabilization
- Can be UPWARD (CABO spiked on a financing report)
- Extreme-volume-spike no-news pause (GNLN) → defer to the flush algorithm, not the flat 10%

### News / Regulatory Halt — codes T1 / T2 / T3 / T12 — News UNKNOWN
- T1 = news pending; T2 = news released; T3 = news and resumption times
- T12 = additional information requested by Nasdaq → treat as WAITING ON NEWS
- WAIT for the news first, then analyze and decide
- Risk of waterfall halts if the news is catastrophic
- Brent's "newscheck" tool (2-minute polling) may surface the release before web search (SVCC)

### News Halt — News ALREADY KNOWN
- Positive news → stock spikes, no play
- Negative news, no red flags → 10% under the halt price
- Negative news, red flags → deeper entry or pass

### Waterfall Halt Warning Signs
- Multiple stacked red flags
- Catastrophic news (Chapter 11, fraud, SEC investigation)
- Thin-liquidity penny stocks
- Asian stocks with extreme selling pressure
- Toxic dilution (convertibles at sub-penny prices, zero-price warrants)
- LULD cascade in progress (repeated M/LUDP pauses)
- Distressed fundamentals (debt >> cash, going concern, recent reverse split)
- Self-disclosed repayment risk on stacked debt (VWAV)
- **[v11] SPAC merger – first day with a thin float, unknown redemptions and an equity line (EVRL)**

## SPAC MERGER RULES (VRXA, BKHA, EVRL Lessons)

**What a SPAC / de-SPAC is:** A SPAC (Special Purpose Acquisition Company) is a "blank-check" shell with no business; it raises money in an IPO (usually $10/share), parks it in a trust, and looks for a private company to merge with. The "de-SPAC" is the merger itself: the shell disappears and the private company becomes public under a new name/ticker. Before the merger, SPAC holders can redeem for ~$10 from the trust — often 90%+ do — leaving little cash and a thin float.

**Regular merger vs SPAC merger:**
| | Regular merger | SPAC merger (de-SPAC) |
|---|---|---|
| Who's merging | Two real operating companies | Empty shell with cash + a private company |
| Price history | Real trading history | Shell near $10 trust, often a pre-deal spike |
| Shareholders | Long-term holders stay | Most SPAC holders redeem → thin float |
| New supply | Limited and known | Sponsor/advisor shares, equity lines (Yorkville) |
| Business | Usually established | Often small, unproven, money-losing |
| Day one | Normal news reaction | Wild swings, often a steep slide |
| Tier | Acquirer 40% [JAY] | First day 85% / STAY AWAY |

Checklist:
- Did this come from a SPAC merger? ("Acquisition Corp" on either side, "business combination," "begins trading," "debuts")
- Announced, or first day under the new ticker?
- Redemption rate (or "not disclosed")
- SPAC + 90%+ redemptions → STAY AWAY entirely
- SPAC + redemption rate unknown → 65% minimum (announcement); first day → 85%/STAY AWAY
- SPAC + moderate redemptions → 52-60%
- Less than 2 weeks trading history → flag and be very cautious
- Preclinical biotech + SPAC → extremely dangerous
- Cayman Islands + SPAC → double caution (incl. Cayman shells that redomicile at closing — EVRL)
- Cayman Islands + Chinese + SPAC → triple STAY AWAY
- Old SPACs with many extension votes usually have near-total redemptions (BBCI)
- Equity line (Yorkville SEPA) announced at closing → 85% or don't go in
- Who's locked up? Only the majority holder = everyone else can sell day one
- Old ticker's prior-day move: big pre-debut spike = inflated baseline
- [CLAUDE-SUGGESTED, v7] A SPAC shell can trade for months/years before announcing a target (WENN, SVCC)
- [CLAUDE-SUGGESTED, v8] The shell's own working-capital deficit matters separately from the trust (SVCC)

VRXA red flags (never again): 99.67% redemptions, preclinical biotech only, $27.5M senior secured debt day 1, $50M dilution agreement, only 5 days trading, Swiss company via SPAC.

EVRL red flags (never again): first day after closing, Cayman shell, redemptions undisclosed, $200M Yorkville equity line, only the majority holder locked up, no financials in the release, old ticker +62% the day before. Entered at 40% without a check → -42.6%.
